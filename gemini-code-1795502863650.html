生產線 Cycle Time 與閒置時間互動計算器

上傳 CSV 檔案後，自動呈現步驟 3 資料、計算各工作站與整條生產線 Cycle Time、工作站閒置時間與長條圖，方便自行驗算。

1. 上傳 CSV 檔案

支援兩種常見 CSV 格式：
• 長表格式：例如欄位包含 item / product / job、station / workstation / 工作站、time / duration / cycle_time / 工時（每列一筆加工紀錄）。
• 寬表格式：例如第一欄為產品/工件編號，其餘欄位為各工作站（如 Station1、Station2、Station3 或 工作站1）的加工時間。
